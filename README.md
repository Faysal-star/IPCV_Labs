# চিত্রসভা


## Labs
- [Lab 1 – Convolution](Lab/Lab_1_Convolution.ipynb): Manual Convolution, Gaussian & Derivative filters.
- [Lab 2 – Edge Detection & ZS Thresholding](Lab/Lab_2_Edge_Detection_ZS_Thresholding.ipynb): Zero-Cross thresholding after applying LoG filter (Laplacian of Gaussian).
- [Lab 3 – Histogram Equalization](Lab/Lab_3_Histogram_Eq.ipynb): RGB and HSV channel histogram equalization.
- [Lab 4 – Region Descriptors](Lab/Lab_4_Region_Descriptors.ipynb): Computing Geometric features and region descriptors to describe shapes and calculate distances (KL Divergence, Euclidean Distance, Cosine Similarity) between shapes.
- [Lab 5 – Frequency Domain Filtering](Lab/Lab_5_Frequency_Domanin_Filtering.ipynb): Fourier-based filters for denoising periodic noise.


## Assignments
- [Assignment 1.1 – Convolution](Assignment/1_1_Convolution.ipynb): Kernel Generation from function and manual convolution implementation.
- [Assignment 1.2 – SVD](Assignment/1_2_SVD.ipynb): Singular Value Decomposition for separable convolution.
- [Assignment 2 – Robust Laplacian Edge Detection](Assignment/2_Robust_Laplacian_Edge_Detection.ipynb): Zero-Cross thresholding with adaptive threshold selection using Local Variance.
- [Assignment 3 – Histogram Matching & Double Gaussian](Assignment/3_Histogram_Matching_Double_Gaussian.ipynb): Double Gaussian Histogram Matching.
- [Assignment 4 – Hu Moments](Assignment/4_Hu_Moments.ipynb): Hu invariant moments for shape comparison and calculating shape similarity using Chi-squared distance.
